隱私權政策

最後更新日期：2026 年 11 月 2 日

SpendWise 是世新大學資訊管理學系的畢業專題，透過 LINE 官方帳號提供消費分析、記帳與信用卡優惠推薦。本政策說明 SpendWise 收集哪些資料、如何使用與儲存，以及你可以如何刪除這些資料。

一、我們收集的資料

  • LINE 使用者 ID：LINE 平台提供的識別碼，用來區分不同使用者。我們不會取得你的 LINE 密碼、好友名單或聊天紀錄。
  • 你自行輸入的卡片資料：你登記的銀行名稱與卡片名稱。我們不收集信用卡卡號、有效期限或安全碼。
  • 你的消費紀錄：日期、金額、店家、類別、備註、來源（手動記帳、拍照記帳、Gmail 匯入等）；外幣消費另外記錄原幣金額與換算匯率；有讀到統一發票號碼時也會記錄發票號碼，用來找出重複的紀錄。
  • 收據照片：使用「拍照記帳」或聚餐分帳拍收據時，照片會送給 Anthropic 辨識店家、日期與金額。照片本身和辨識結果都不會存進資料庫，辨識時也不會附上你的 LINE 使用者 ID；只有在你看過確認卡、按下「確認送出」後，確認卡上的內容才會存成你的一筆消費紀錄。
  • 信用卡卡面照片：使用「拍卡面新增」時，照片會送給 Anthropic 辨識發卡銀行、卡片名稱與卡別。照片本身和辨識結果都不會存進資料庫，辨識時也不會附上你的 LINE 使用者 ID；若辨識結果中出現疑似卡號的數字，該筆結果會直接捨棄。只有在你選擇「新增這張卡」後，才會存下銀行與卡片名稱。建議拍攝時用手指遮住卡號，也請勿拍攝卡片背面。照片仍會留在 LINE 聊天紀錄中，建議傳送後 24 小時內長按照片選擇「收回」。
  • 位置：使用「附近優惠查詢」時你主動分享的位置，或你輸入的地點名稱，用來查詢附近的店家，查完不會儲存。如果你訂閱附近的店家或某個地區的優惠，會儲存該位置的座標與地址（詳見「六、資料儲存、保存期間與安全」）。
  • 優惠訂閱：你訂閱的店家、銀行或地區，以及你選的通知類型（新優惠通知、優惠到期通知）。
  • AI 對話內容：你向 SpendWise 提問時輸入的文字，用來產生回覆。對話記憶只暫存在伺服器的記憶體中，超過 30 分鐘沒有對話就會清除，不會存進資料庫。
  • 為你推薦的結果：使用「為你推薦」時，會儲存這次推薦了哪些優惠、推薦理由與摘要（例如最常去的店家、花最多的類別），用來在 24 小時內直接顯示同一份結果，以及避免近期重複推薦同一筆優惠。
  • 你的 Anthropic API 金鑰（選用）：如果你自行設定，金鑰會加密存放，只用來替你呼叫 AI 功能。
  • Gmail 資料（僅在你連結 Gmail 後）：詳見下方「二、Gmail 資料」。

二、Gmail 資料

只有在你主動連結 Gmail 後，SpendWise 才會讀取你的 Gmail。連結方式有兩種，同一時間只能使用其中一種：

連結方式一：Google 帳號授權

點選「用 Google 帳號連結」，在 Google 的同意畫面按下允許。SpendWise 只申請 Gmail 唯讀權限（gmail.readonly）：只讀不寫，不會寄信、不會刪信，也不會修改、標記或移動任何信件。授權 token（連同你的 Gmail 地址）會加密存放。

連結方式二：Gmail 應用程式密碼

  • 點選「用應用程式密碼連結」，會用手機的瀏覽器開啟 SpendWise 的輸入頁面，在那裡輸入你的 Gmail 地址和在 Google 帳戶產生的應用程式密碼。請不要把密碼貼在 LINE 聊天室；如果在聊天室打出像應用程式密碼的文字，SpendWise 會直接提醒你，不會儲存。
  • 送出後 SpendWise 會先用這組密碼登入確認，成功才儲存。Gmail 地址和應用程式密碼會一起加密存放，密碼不會出現在伺服器紀錄中。為了防止有人一直嘗試，每次送出會記錄你的 LINE 使用者 ID 和時間（15 分鐘內最多 5 次），超過 24 小時的紀錄會在之後有人送出時一併清掉。
  • 讀取時只用唯讀方式：只讀不改，不會寄信、刪信、移動信件，也不會把信件標成已讀。
  • 應用程式密碼是你在 Google 帳戶產生的，SpendWise 無法替你刪除 Google 那邊的這組密碼；解除連結後，建議你也到 Google 帳戶刪除它。

讀取哪些內容

  • 找發票信：SpendWise 只會搜尋最近 6 個月內、主旨含有發票相關關鍵字（例如「電子發票」「統一發票」）的信件，最多 1,000 封，再讀取這些信件的主旨確認是否為發票信。主旨不會儲存，只記錄信件 ID 與「是否為發票信」，避免重複判斷。打開「消費分析」時也會用同樣的方式檢查有沒有新的發票信。
  • 發票信內容：只有在你按下「更新消費紀錄」（或「繼續匯入」）時，才會讀取發票信的主旨、寄件者、內文，以及 PDF／HTML 附件中的文字；每按一次最多處理 20 封。
  • 你的 Gmail 地址：在 LINE 中顯示「已連結：你的信箱」，讓你確認連結的是自己的帳號。

如何處理

發票信的內容（每封最多前 3,000 字）會透過 Anthropic 的 Claude API 解析，取出店家、日期、金額、發票號碼與消費類別，存成你的消費紀錄。有設定自己的 API 金鑰時使用你的金鑰；還沒有設定的人，第一次更新會由 SpendWise 的金鑰免費解析（見「三、AI 功能與試用額度」）。

信件內文、主旨與附件不會儲存；資料庫只保留解析出的消費紀錄，以及對應的信件 ID 與處理狀態（已匯入、不是發票、解析失敗、你刪掉的），用來避免重複匯入。

解除連結

解除連結後：使用 Google 帳號授權的，SpendWise 會向 Google 撤銷授權，並刪除資料庫中的授權 token 與 Gmail 地址；使用應用程式密碼的，會刪除加密保存的應用程式密碼與 Gmail 地址。已匯入的消費紀錄會保留，信件 ID 的處理紀錄也會保留（重新連結時才不會重複匯入）；如需刪除，請見「七、如何刪除你的資料」。

Google API 服務使用者資料政策

SpendWise's use and transfer of information received from Google APIs to any other app will adhere to Google API Services User Data Policy, including the Limited Use requirements.

SpendWise 使用從 Google API 取得的資訊，以及將這些資訊傳輸至任何其他應用程式時，將遵守 Google API 服務使用者資料政策，包括其中的「有限使用」要求。

三、AI 功能與試用額度

  • AI 試用額度：直接打字問問題、為你推薦、拍照記帳、聚餐分帳拍收據、拍卡面新增會用到 AI。沒有設定自己 API 金鑰的人，可以使用 SpendWise 提供的每日試用額度，用完隔天重置；設定自己的金鑰後改用你的金鑰，不受試用額度限制。
  • 第一次免費解析發票信：還沒有設定自己 API 金鑰的人，第一次按「更新消費紀錄」時，會由 SpendWise 的金鑰免費解析最近 10 封發票信，每人限一次。
  • 使用紀錄：為了計算試用額度與免費解析次數，SpendWise 會記錄：試用額度——你的 LINE 使用者 ID、日期、當天用掉的 AI 費用（美元）、更新時間；免費解析——你的 LINE 使用者 ID、是否已經用過（狀態）與時間，以及每天用掉的 AI 費用。這些紀錄不包含你問的問題、照片或信件內容，目前會長期保存，不會自動刪除。
  • 常見用法問題的回答：像「日期可以怎麼打」「要怎麼離開」這類跟個人資料無關的用法問題，AI 的回答會暫存在伺服器的記憶體中 24 小時，讓之後問同樣問題的人可以直接看到答案。只會暫存不含個人資料的問題與回答，不包含你的 LINE 使用者 ID 或任何身分資料，也不會存進資料庫；跟你的消費、卡片、記帳等有關的問題不會暫存。

四、資料用途

上述資料只用於以下功能：

  • 消費分析與消費報告
  • 記帳（手動記帳、拍照記帳、Gmail 發票匯入）與找出重複的消費紀錄
  • 信用卡與店家優惠推薦、聚餐分帳，以及你訂閱的新優惠通知與優惠到期提醒

我們不販售你的資料，也不將你的資料提供給第三方做廣告用途。SpendWise 沒有任何廣告。

五、協助提供服務的第三方

為了提供上述功能，部分資料會傳送給以下服務，僅限於完成該功能所需：

  • LINE：傳遞你與 SpendWise 之間的訊息與通知。
  • Google：Gmail（讀取發票信）、Places API（依你分享的位置或輸入的地點查詢附近店家）。
  • Anthropic（Claude API）：解析發票信、收據照片與信用卡卡面照片、產生 AI 回覆與優惠推薦說明。
  • Supabase：存放資料庫。

六、資料儲存、保存期間與安全

  • 資料存放於 Supabase 提供的 PostgreSQL 資料庫。
  • Gmail 授權 token（連同你的 Gmail 地址）、Gmail 應用程式密碼（連同你的 Gmail 地址）與你的 Anthropic API 金鑰，都以加密方式存放於資料庫。
  • 伺服器紀錄（log）中的 LINE 使用者 ID、信箱、token、密碼與金鑰都會遮蔽或不記錄。
  • 優惠訂閱與位置：訂閱附近的店家或地區時，會儲存位置座標、地址、訂閱的店家，以及通知類型。當你在 SpendWise 取消訂閱時，我們會立即刪除該筆訂閱紀錄，包括你訂閱時分享的位置座標與地址；已取消的訂閱不會再保留任何位置資料。
  • 重複的消費紀錄：同一筆消費被記了兩次（例如拍照記帳之後又從 Gmail 匯入同一張發票）時，SpendWise 會把兩筆合併。合併後被取代的那一筆仍會保留在資料庫中，但不再計算進任何統計，你可以按「復原」把它放回來；刪除保留的那一筆時，被合併的那一筆會一起刪除。
  • 通知紀錄：為了避免同一則優惠重複通知，會記錄通知過你哪些優惠與日期。

七、如何刪除你的資料

你可以在 LINE 的 SpendWise 官方帳號中自行操作：

  • 解除 Gmail 連結：我的管理 → 我的資料 → Gmail 連結 → 解除連結。刪除哪些資料請見「二、Gmail 資料」的「解除連結」。使用 Google 帳號授權的，也可以到 Google 帳戶的第三方存取設定 移除 SpendWise 的權限；使用應用程式密碼的，建議到 Google 帳戶的應用程式密碼頁面 刪除那組密碼。
  • 刪除消費紀錄：我的管理 → 我的資料 → 刪除消費紀錄，可以刪除單筆或清空全部（合併在那筆裡的重複紀錄會一起刪除）。刪除從 Gmail 匯入的紀錄後，那封發票信會記成「你刪掉的」，之後不會再自動匯入。
  • 刪除已登記的卡片：我的管理 → 我的卡片 → 刪除卡片。
  • 刪除你的 API 金鑰：我的管理 → 我的資料 → 刪除我的 API Key。
  • 取消優惠訂閱：我的管理 → 我的訂閱 → 取消訂閱，會立即刪除那筆訂閱與它的位置資料。

如果你希望刪除與你的 LINE 使用者 ID 相關的所有資料（包含上述以外的紀錄，例如 Gmail 信件 ID 的處理紀錄、試用額度與免費解析的使用紀錄、為你推薦的結果、通知紀錄），請來信下方聯絡信箱，我們會協助處理。
