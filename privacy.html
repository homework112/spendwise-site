隱私權政策

最後更新日期：2026 年 10 月 9 日

SpendWise 是世新大學資訊管理學系的畢業專題，透過 LINE 官方帳號提供消費分析、記帳與信用卡優惠推薦。本政策說明 SpendWise 收集哪些資料、如何使用與儲存，以及你可以如何刪除這些資料。

一、我們收集的資料

  • LINE 使用者 ID：LINE 平台提供的識別碼，用來區分不同使用者。我們不會取得你的 LINE 密碼、好友名單或聊天紀錄。
  • 你自行輸入的卡片資料：你登記的銀行名稱與卡片名稱。我們不收集信用卡卡號、有效期限或安全碼。
  • 你自行輸入的消費紀錄：日期、金額、店家、類別、備註；外幣消費另外記錄原幣金額與換算匯率。
  • 收據照片：使用「拍照記帳」或聚餐分帳拍收據時，照片只用來辨識店家、日期與金額，照片本身不會儲存。
  • 位置：使用「附近優惠查詢」時你主動分享的位置，用來查詢附近的店家；如果你訂閱某個地區的優惠，會儲存該位置的座標與地址。
  • AI 對話內容：你向 SpendWise 提問時輸入的文字，用來產生回覆。
  • 你的 Anthropic API 金鑰（選用）：如果你自行設定，金鑰會加密存放，只用來替你呼叫 AI 功能。
  • Gmail 資料（僅在你授權後）：詳見下方「二、Gmail 資料」。

二、Gmail 資料

只有在你主動點選「連結 Gmail」並在 Google 同意畫面按下允許後，SpendWise 才會存取你的 Gmail。

權限範圍

SpendWise 只申請 Gmail 唯讀權限（gmail.readonly）：只讀不寫，不會寄信、不會刪信，也不會修改、標記或移動任何信件。

讀取哪些內容

  • 信件主旨：為了找出發票通知信，會讀取最近 6 個月內、最多 50 封信件的主旨，判斷是否含有「電子發票」「統一發票」等關鍵字。主旨不會儲存，只記錄信件 ID 與「是否為發票信」，避免重複判斷。
  • 發票通知信內容：在你按下「更新消費紀錄」時，才會讀取被判斷為發票信的信件主旨、寄件者、內文，以及 PDF／HTML 附件中的文字。
  • 你的 Gmail 地址：在 LINE 中顯示「已連結：你的信箱」，讓你確認連結的是自己的帳號。

如何處理

發票通知信的內容（每封最多前 3,000 字）會透過 Anthropic 的 Claude API，使用你自己設定的 API 金鑰進行解析，取出店家、日期、金額與消費類別，存成你的消費紀錄。

信件內文、主旨與附件不會儲存；資料庫只保留解析出的消費紀錄，以及對應的信件 ID（用來避免重複匯入）。

Google API 服務使用者資料政策

SpendWise's use and transfer of information received from Google APIs to any other app will adhere to Google API Services User Data Policy, including the Limited Use requirements.

SpendWise 使用從 Google API 取得的資訊，以及將這些資訊傳輸至任何其他應用程式時，將遵守 Google API 服務使用者資料政策，包括其中的「有限使用」要求。

三、資料用途

上述資料只用於以下功能：

  • 消費分析與消費報告
  • 記帳（手動記帳、拍照記帳、Gmail 發票匯入）
  • 信用卡與店家優惠推薦，以及你訂閱的優惠到期提醒

我們不販售你的資料，也不將你的資料提供給第三方做廣告用途。SpendWise 沒有任何廣告。

四、協助提供服務的第三方

為了提供上述功能，部分資料會傳送給以下服務，僅限於完成該功能所需：

  • LINE：傳遞你與 SpendWise 之間的訊息。
  • Google：Gmail API（讀取發票通知信）、Places API（依你分享的位置查詢附近店家）。
  • Anthropic（Claude API）：解析發票信與收據照片、產生 AI 回覆與優惠推薦說明。
  • Supabase：存放資料庫。

五、資料儲存與安全

  • 資料存放於 Supabase 提供的 PostgreSQL 資料庫。
  • Gmail 授權 token（連同你的 Gmail 地址）與你的 Anthropic API 金鑰，都以加密方式存放於資料庫。
  • 伺服器紀錄（log）中的 LINE 使用者 ID、信箱、token 與金鑰都會遮蔽或不記錄。

六、如何刪除你的資料

你可以在 LINE 的 SpendWise 官方帳號中自行操作：

  • 解除 Gmail 連結：我的管理 → 我的資料 → Gmail 連結 → 解除連結。SpendWise 會向 Google 撤銷授權，並刪除資料庫中的 Gmail 授權 token 與 Gmail 地址。已匯入的消費紀錄會保留，如需刪除請見下一項。你也可以到 Google 帳戶的第三方存取設定 移除 SpendWise 的權限。
  • 刪除消費紀錄：我的管理 → 我的資料 → 刪除消費紀錄。
  • 刪除已登記的卡片：我的管理 → 我的卡片 → 刪除卡片。
  • 刪除你的 API 金鑰：我的管理 → 我的資料 → 刪除我的 API Key。
  • 取消優惠訂閱：在「我的訂閱」中取消。

如果你希望刪除與你的 LINE 使用者 ID 相關的所有資料（包含上述以外的紀錄，例如 Gmail 信件 ID 的處理紀錄），請來信下方聯絡信箱，我們會協助處理。
